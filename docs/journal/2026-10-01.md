## X-58 텍스트 편집 컨텍스트 메뉴 + Edit 메뉴 클립보드 4종(사용자 요청 2건 — `16dd5d9`)

**요청**: ① 경로 바(breadcrumb)를 우클릭하면 편집 모드(전체 선택)로 들어가지만 **편집 중 우클릭에 아무 동작이
없다** — 설정 창의 글꼴 입력란(네이티브 EDIT)처럼 **시스템 메뉴로 복사·잘라내기·붙여넣기·전체 선택**을 구현할 수
있는가. Info·Preview·Terminal 패널도 우클릭 동작 없음. ② (추가) **풀다운 Edit 메뉴에도 해당 기능이 없으니 동시 구현**.

**원인(구조)**: 경로바 편집·이름변경·도크·터미널은 전부 **커스텀 드로잉**(DR-1 — 네이티브 EDIT 컨트롤이 아님)이라
OS가 주는 편집 메뉴가 없다. 설정 창만 `w!("EDIT")` 자식 컨트롤이라 메뉴가 보였다([prefs.rs](../../crates/nexa-app/src/prefs.rs)).
클립보드 동작 자체는 단축키 경로에 이미 있었다(경로바/이름변경 Ctrl+C/X/V = QA 07-14 · 도크 텍스트 Ctrl+C = QA 07-15 ·
터미널 Ctrl+C/V = WM_CHAR 0x03/0x16) — **진입점(우클릭·메뉴)만 없던 것**.

**구현** — 네이티브 팝업(`TrackPopupMenuEx` — 탭 메뉴·툴바 팝업과 같은 재진입 규약: State 참조 종료 후 표시, 결과만 재획득):
