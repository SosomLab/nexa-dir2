## X-46 압축 파일 미리보기 — 목록 계층·그리드 창·암호·플러그인 ABI v2 (사용자 요청)

**요청**(원문 요지): *"압축파일 미리보기(그리드 방식, 파일 그리드 재활용 가능),
별도창 보기·내장 지원 모두. 암호가 필요하면 입력받되 **전달만 하고 기록되거나 Plain으로
노출되지 않도록**. 플러그인은 별도 개발 후 최종 파일만 배포하는 용도로. 이 미리보기는
프로젝트에 포함시켜 샘플로도. 알려진 압축 포맷 지원 + **설계상 확장 용이**."*

브랜치 `feat/x46-archive-preview` — 6커밋. 설계 SSOT = [28](../28-archive-preview.md).

### 1) 관점 정리 — "미리보기는 압축을 풀 필요가 없다"

착수 전 확인한 사실이 설계 전체를 결정했다: **거의 모든 압축 포맷은 항목 표가 평문**
이다(zip 중앙 디렉터리·tar 512B 헤더·cab CFFILE·rar 블록 헤더). 즉 코덱 없이도
이름·크기·시각·암호화 여부를 읽을 수 있고, 미리보기의 관심사("무엇이 들어 있나")는
그것으로 충분하다. 예외는 **헤더 자체가 압축되는 7z**(기본값 -mhe 아님에도 헤더는
LZMA) — 여기만 "코덱 필요 = 플러그인 담당"으로 정직하게 분리했다.

덕분에 **외부 crate 0(DR-8)**을 유지하면서 알려진 포맷 대부분을 내장할 수 있었다.

### 2) 목록 계층 = nexa-vfs(포맷 레지스트리)

위치를 nexa-app이 아니라 **nexa-vfs**로 잡은 이유: (a) OS 비의존이라 맥/리눅스에서도
`cargo test`로 검증되고, (b) 훗날 "아카이브를 폴더처럼 탐색"(VFS 공급자)으로 확장할 때
같은 계층에 그대로 얹힌다.

- 모델 통일 = `ArchiveEntry`/`Listing` 하나(도크·그리드·플러그인 ABI 공용) +
  `ReadAt`(파일·메모리·후속 원격을 같은 계약으로).
- **확장 규약**(요청의 "확장 용이") = **파일 1개 + `FORMATS` 한 줄**. 확장자 선언·
  sniff·라우팅·컬럼은 전부 레지스트리에서 파생돼 그 외에는 고칠 곳이 없다.
- 내장 리더 = ZIP(Zip64·AES/ZipCrypto 표시·**SFX 델타 보정**·CD 암호화 = 암호 요구) ·
  TAR(ustar/GNU L/PAX/base-256) · CAB(폴더 압축 방식까지) · RAR 5/4 · 7z(판정) ·
  gzip/bz2/xz/zstd/lz4/lzip 단일 스트림.
- 안전: 경로 탈출(zip slip) 정규화 + `suspicious` 표시 · 전 오프셋 범위 검사(손상
  파일에 패닉 없음) · 항목/이름/읽기 상한.
- 테스트 30 — **픽스처를 바이트 규약으로 직접 조립**(외부 도구·바이너리 동봉 0).
  이 방식이 규격 이해를 강제해서, 실제로 RAR5 블록 경계·PAX 레코드 길이 계산의 오류를
  테스트가 먼저 잡았다.

### 3) 표시 — 도크는 요약, 별도 창은 그리드

- 요청의 "파일 그리드 재활용"은 **NxGrid**([ctl/grid.rs](../../crates/nexa-app/src/ctl/grid.rs))로
  받았다. 파일 목록과 같은 규약(헤더 리사이즈·정렬 3상태·다중 선택·오버레이 스크롤바)을
  이미 갖춘 앱의 그리드 라이브러리라, 새 창에 그대로 얹으면 규약이 자동으로 따라온다.
  컬럼 8종·수치 정렬(크기/시각/압축률)·`Esc`·`Ctrl+C`(TSV 복사).
- 하단 도크는 축약(포맷·개수·크기·절감률·암호/솔리드/분할 표시 + 앞 60개 항목).
  F3·도크 ↗가 압축이면 텍스트 창 대신 **그리드 창**으로 라우팅하고, 목록은 시임이
  이미 읽은 결과를 그대로 넘겨 **재조회하지 않는다**.
- **시각 이중 보정 함정**: DOS 시각(zip·cab·rar4)은 시간대가 없어 값이 곧 현지
  벽시계인데, 여기에 로컬 오프셋을 또 더하면 9시간이 밀린다. `time_is_local`을 항목에
  두고 zip은 **확장 필드(NTFS/UT)가 있으면 UTC, 없으면 현지**로 갈랐다.
- 구형 zip의 CP949 한글 이름 → 호스트 디코더(`MultiByteToWideChar(CP_ACP)`) 주입.

### 4) 암호 — "전달만, 기록·평문 노출 금지"를 타입으로 강제

지시를 문장으로만 지키지 않고 **구조로** 지켰다.

- `nexa-core::secret::Secret` 신설 — `Debug`는 `Secret(***)`(**길이도 비노출**) ·
  `Display`/`AsRef<str>`/직렬화 없음 · Drop에서 `write_volatile` 0 덮기(컴파일러 펜스) ·
  용량 선확보(재할당으로 미소거 사본이 흩어지지 않게).
- 입력 모달 = 마스킹 EDIT(복사·잘라내기 불가) + "암호 표시" 토글. **회수 즉시** Secret로
  이동하고 경유 UTF-16 버퍼·컨트롤 내용·되돌리기 버퍼를 지운다. 창 상태에 값을 남기지
  않는다.
- 보관은 **세션 메모리 한 곳뿐**이고 파일 저장 경로가 코드에 아예 없다(토큰용 DPAPI
  경로와 의도적 분리 — 토큰은 재로그인 회피가 목적이지만 암호는 그럴 이유가 없다).
  틀린 암호는 즉시 폐기 후 재시도 안내.
- 플러그인에도 같은 원칙: 활성 슬롯 주입 → 호출 종료 시 소거, 게스트 메모리는 인스턴스
  폐기와 함께 사라진다.

### 5) 플러그인 ABI v2 + 샘플(최종 파일만 배포)

- `nx_meta` **4번째 줄 = 능력 선언**(`archive`)으로 하위 호환 확장. `nx_archive()`는
  `archive`/`password`/`error` 세 종류를 돌려주고, 호스트 임포트에 `file_size`·
  `read_at`(꼬리부터 읽는 포맷용)·`password`가 붙었다.
- 참조 구현 [`samples/archive-viewer-wasm`](../../samples/archive-viewer-wasm/) —
  **내장이 다루지 않는** ISO 9660(Joliet 포함)·ar·cpio를 **31KB `.wasm` 하나**로.
  배포 = `data\plugins\` 복사 + 재시작(앱 재빌드 없음) = 요청의 "별도 개발 후 최종 파일만
  배포"가 그대로 성립한다.
- E2E 테스트가 동봉 `dist/archive.wasm`을 실제 wasmi로 로드해 세 포맷 목록을 검증한다
  (ISO 이미지는 테스트가 규약대로 조립 — 바이너리 픽스처 없이).
