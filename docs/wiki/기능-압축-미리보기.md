# 압축 파일 미리보기

`0.18.0`부터 **압축 파일 안에 무엇이 들어 있는지**를 압축을 풀지 않고 바로 볼 수 있습니다.
파일을 선택하면 하단 도크에 요약이 뜨고, **F3**(또는 도크 우상단 **↗**)로 **그리드 창**을
열면 파일 목록과 같은 방식으로 정렬·선택·복사할 수 있습니다.

> 압축을 **풀지 않습니다.** 임시 폴더도 만들지 않고, 목록만 읽습니다(대부분의 압축 형식은
> 항목 표가 평문으로 들어 있습니다). 그래서 수 GB짜리 파일도 목록은 즉시 뜹니다.

---

## 지원 형식

| 형식 | 확장자 | 비고 |
| --- | --- | --- |
| ZIP 계열 | `zip` `zipx` `jar` `apk` `docx` `xlsx` `pptx` `epub` `whl` `appx` … (26종) | Zip64 · 암호 항목 표시 |
| TAR | `tar` | 긴 이름(GNU·PAX) 포함 |
| CAB | `cab` | 압축 방식(MSZIP/LZX) 표시 |
| RAR | `rar` `r00` `rev` | RAR 5 · RAR 4 |
| 단일 스트림 | `gz` `tgz` `bz2` `xz` `zst` `lz4` `lz` `lzma` `z` … | 항목 1건(gzip은 원래 이름·크기까지) |
| 7z | `7z` | 헤더 자체가 압축돼 있어 **플러그인이 필요**하다는 안내가 뜹니다 |
| ISO·ar·cpio | `iso` `a` `deb` `lib` `cpio` | **동봉 플러그인**(`archive.wasm`)이 처리 |

---

## 보는 방법

1. 압축 파일을 **한 개** 선택합니다.
2. **하단 도크 → 미리보기** — 형식·파일/폴더 수·원본↔압축 크기·절감률과 앞부분 항목이 보입니다.
3. **F3** 또는 도크 우상단 **↗** — **압축 그리드 창**이 열립니다.

### 그리드 창

| 열 | 내용 |
| --- | --- |
| 이름 / 경로 | 항목 이름과 압축 파일 안에서의 폴더 경로 |
| 크기 / 압축 크기 / 압축률 | 원본, 압축 후, 절감 비율 |
| 방식 | `Store` `Deflate` `LZMA` `AES-256 + Deflate` 등 |
| 수정한 날짜 | 압축 파일에 기록된 시각 |
| 표시 | `폴더` · `잠김`(암호로 보호된 항목) · `위험 경로`(아래 참고) |

- **정렬**: 열 제목 클릭(크기·날짜·압축률은 숫자 기준으로 정렬됩니다).
- **선택·복사**: 파일 목록과 같은 방식(클릭·Shift·Ctrl·`Ctrl+A`) → **`Ctrl+C`** 로 선택한
  행을 탭 구분 텍스트로 복사(엑셀에 그대로 붙여넣기 가능).
- **닫기**: `Esc`.
- 창 아래 상태 줄에 형식·항목 수·총 크기와 **암호 포함 / 솔리드 / 분할** 여부가 표시됩니다.

## 암호가 걸린 압축 파일

- **항목 이름만 잠긴 경우가 아니라면 목록은 그대로 보입니다.** 일반적인 암호 zip은
  이름·크기는 보이고 **내용만** 잠기므로, 표시 열에 `잠김`으로 나타납니다.
- **목록 자체가 암호화**된 경우(RAR 헤더 암호화, 7z `-mhe=on`, ZIP 강력 암호화)에는
  창을 열 때 **암호 입력창**이 뜹니다. 틀리면 다시 물어봅니다.

> 🔐 **입력한 암호는 저장되지 않습니다.** 화면에는 ●로 가려지고(원하면 "암호 표시"로 확인),
> 읽기에 전달된 뒤 즉시 메모리에서 지워집니다. 설정 파일·로그·창 제목 어디에도 기록하지
> 않으며, 같은 파일을 다시 열 때만 쓰도록 **앱이 켜져 있는 동안에만** 기억합니다
> (앱을 끄면 사라집니다).

---

## 안전 표시 — `위험 경로`

압축 파일 안의 항목이 `..\..\` 같은 **상위 폴더 탈출 경로**나 절대 경로(`C:\...`)를
갖고 있으면 표시 열에 **`위험 경로`** 로 알려 줍니다. 미리보기는 읽기 전용이라 그 자체로
위험하지 않지만, 그런 압축 파일을 다른 도구로 풀 때는 주의해야 합니다.

---

## 플러그인으로 형식 늘리기

`iso` · `ar`(`.deb`·`.lib`) · `cpio`는 **동봉 플러그인 `archive.wasm`** 이 읽습니다.
포터블 zip과 설치본에는 이미 들어 있고, 단일 exe만 받았다면 릴리스의
`NexaDir-Plugins-<버전>.zip`을 exe 옆에 풀면 됩니다 →
[설치와 다운로드](설치와-다운로드).

직접 형식을 추가하고 싶다면 `.wasm` 하나로 만들 수 있습니다(앱 재빌드 불필요) →
[플러그인 개발](개발-플러그인).

---

## 알아 두기

- 미리보기는 **목록만** 보여 줍니다. 압축 안의 파일 내용을 열거나 압축을 푸는 기능은
  아직 없습니다(탐색기·7-Zip 등으로 열면 됩니다).
- `.tar.gz`처럼 **tar을 다시 압축한 파일**은 안쪽 tar 1건으로 보입니다(안쪽 목록까지
  보려면 압축을 풀어야 하기 때문).
- 목록이 아주 많으면(5만 개 초과) 앞부분만 표시하고 상태 줄에 알려 줍니다.
- 오래된 압축 파일의 한글 이름(CP949)도 Windows 코드페이지로 해석해 정상 표시합니다.
